# DESIGN.md

## 气质与意象
- 关键词：手记、作品集、暖纸、极简、私人感
- 场景叙述：一本翻开在桌面上的笔记本，里面贴着三张房间的照片——写实的、黄昏的、梵高滤镜的，旁边用手写体写了几行批注。链接不再藏在房间里，而是规规矩矩列在左边，像笔记本内页的索引。

## 版式（参照 oblivio minimal 页面的极简骨架）
- 顶部条：品牌名 + 手写备注 + 状态（3 rooms · one life）
- 左栏：名字 / 手记一句 / 链接清单（编号 01-05）/ 改版备注 / 返回主页
- 主区：三张房间图 = 三幅"作品"，图带细线裱框（白色 mat + hairline），配手写体标题 + 小字 meta
- 底部：手写签名行 + 状态

## 配色方案
- 纸底：暖米白 `#faf7f1`
- 墨色：`#1b1814` / 柔和 `#71685c` / 淡 `#a99f90`
- 发丝线：`#e6dfd3`
- 强调：暖琥珀 `#a34e1f`（呼应房间的琥珀台灯）

## 字体排版
- 手写批注：Caveat（标题/备注/签名）
- 品牌/名字：Cormorant Garamond（斜体衬线）
- UI 文字：DM Sans（小号大写字母距）

## 动效与交互
- 图片轻微倾斜（-0.4° / +0.7° / -0.25°），悬停回正 + 轻微上浮 + 柔影——像拿起来看一张照片
- 第二张图向右偏移 11%，刻意不齐整，营造手贴的随意感
- 链接悬停：下划线 + 琥珀色

## 设计禁忌
- 不用 emoji 图标（手记符号 ✎ ✳ ☾ 除外，属于手写批注语言）
- 不使用方框卡片 + 渐变组合
- 不使用冷色调科技蓝
- 不用玻璃拟态 / 大圆角
